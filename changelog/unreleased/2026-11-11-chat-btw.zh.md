# 阅读回复时的临时问答

Date: 2026-11-11
Type: Added
Scope: web, server, core

[English](2026-11-11-chat-btw.md)

划选已完成的 AI 回复中的文字，点击 **btw 提问**，即可在原文旁打开临时对话。每条回复也提供 btw 入口，可针对整条回复提问。手机上，对话显示在屏幕底部。

提问和追问时，原文选区持续高亮。支持停止生成、复制回答，也可保持问答窗口打开并继续滚动主会话。关闭窗口、按 Escape 或离开当前会话后，临时对话清空。

btw 使用当前会话的模型，并读取当前上下文的只读快照。提问和回答仅保存在页面内存中，不进入主会话或 Trace。模型用量计入正常用量统计。
