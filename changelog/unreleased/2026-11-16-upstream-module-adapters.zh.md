# 在官方模块拆分后保留 fork 扩展

- **Date:** 2026-11-16
- **Type:** refactor
- **Scope:** `core`, `server`, `web`, `ui`, `tooling`
- **PR:** [#14](https://github.com/liuneng1994/penguin-harness/pull/14)

[English](2026-11-16-upstream-module-adapters.md)

将 fork 扩展重放到官方的新模块结构。Agent 设置继续提供 Skill 共享与使用统计，文件引用仍能打开代码查看器或配置的编辑器，临时问答与保存的阅读位置继续跟随所属 Session。

## 细节

- Skill 元数据和每个 Agent 的可用性判断保留在独立目录模块中，图标沿用官方仅作为图片读取的实现。「插件」页将共享技能与已安装的插件部件分开展示，并提供开关和使用统计，Project 设置保留手动共享。没有恢复已删除的旧技能标签页和项目弹窗。
- 工作台目录读取与 iframe 展示移入共享库。代码预览使用这些库，与工作台功能模块之间没有依赖环。文件引用解析、编辑器打开和编辑器偏好也移入共享库。
- 文件动作、预览状态和预览弹窗通过独立 hook 接入官方聊天组合。回复文件渲染器和临时问答均保留；临时问答浮窗使用统一层级。
- TRAE 原生模型的默认传输逻辑接入服务端贡献的 CLI 模型命令。Agent 作者字段与全局发现开关并存，远程委派在交给父会话审批时保留官方的审批原因。
- 默认内核标记为 `2026-11-16`，保留官方的审批与记忆脚本默认设置。已编辑的标签页仍受原有更新保护。
- 安装器测试使用 GNU 和 BSD sed 均支持的就地修改参数，保留 Release 工作流的版本标记表达式。
