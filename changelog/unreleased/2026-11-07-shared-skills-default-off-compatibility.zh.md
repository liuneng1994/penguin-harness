# 共享技能默认状态的兼容性

- **Date:** 2026-11-07
- **Type:** feature
- **Scope:** `core`, `server`
- **Breaking:** yes — 消费 Agent 未保存开关时，共享技能不再默认启用。

[English](2026-11-07-shared-skills-default-off-compatibility.md)

缺少开关时的规则永久调整为：独立文件继续启用，引用的 General 共享文件默认关闭。在 Agent 的技能设置中逐项启用需要使用的共享技能。已明确保存的启用或关闭状态继续优先。已有独立文件保留了原有默认状态，包括之前手动同步的副本。

创建新的独立副本或同步副本时，仅在没有设置文件的情况下记录共享技能的默认关闭状态。设置通过原子操作写入，并发保存的用户选择会保留。没有迁移或覆盖技能内容及已有设置。

这一默认规则和已有的 JSON 设置格式永久保留，没有迁移期限或移除步骤。General 自己的默认状态和同 Project 的范围保持不变。
