# 跨节点发现和委派 Agent

Date: 2026-11-11
Type: Added
Scope: core, server, web

[English](2026-11-11-global-agent-discovery.md)

每个 Agent 的运行参数中新增 **全局发现** 开关，默认关闭，已有 Agent 也保持关闭。关闭时，发现和委派都限于本机。

开启后，`list_agents` 可发现已连接节点上同一 Project 的 Agent。控制器复用已有的节点连接转发查询，让远程 Agent 能发现并委派连接到该控制器的其他节点。节点必须属于控制器的当前 Project，且 Project ID 相同。断连或不支持的节点会单独列出。发现操作不会修复或升级节点。

目录包含节点身份、Agent 名称、角色和是否可委派。使用 `node_id` 和 `agent_id` 可查看远程 Agent 已启用的技能名称，也可通过 `run_subagent` 委派任务。目标由模型自行选择。目录查询只传递元数据，响应缓慢的节点不会阻止本机目录返回。

远程委派用于临时数据调研。每个任务在目标节点的独立空工作区中启动，使用目标 Agent 的工具、技能和凭据，不获取或同步代码。输出和审批请求返回父会话；`input_subagent` 支持追问和停止当前轮次。后台任务复用现有的完成通知。父会话断连后心跳停止，远程任务会在租约到期时停止。

委派保持一层，释放后的子会话恢复时也遵守该限制。远程工作区和完整子会话记录保留在目标节点，父会话保留工具结果。开关独立保存，不提交其他未保存的运行参数。调用端、执行端及中间控制器都需要支持远程委派的版本。
