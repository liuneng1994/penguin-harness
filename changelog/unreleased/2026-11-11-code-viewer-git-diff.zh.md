# 在代码预览中直接查看 Git 改动

- **Date:** 2026-11-11
- **Type:** feature
- **Scope:** `server`, `web`, `plugins`
- **PR:** [#6](https://github.com/liuneng1994/penguin-harness/pull/6)

[English](2026-11-11-code-viewer-git-diff.md)

可选的代码查看器在同一个代码视图内显示 Git 改动。新增和修改行带有行旁标记及行内高亮。
原代码直接展示在对应位置下方，并保留原行号。选择代码或提问时，模型引用范围和改动高亮
仍然可见。显示改动开关不会改变源码或选区，
上一个和下一个改动按钮可以在当前文件的修改位置之间跳转。

## 源码和问答

未暂存显示工作区代码，已暂存显示 Git 索引中的代码。复制代码不包含原代码，复制 diff
则复制完整补丁。刷新会一起更新源码和改动。问答读取当前展示的源码及附近 Git 改动，
也支持针对删除的代码提问；快照变化后需要刷新再提问。回复保留在问答浮窗中。

## 文件状态

新增文件显示为新增行，删除文件保留 Git 中的删除行。空文件、二进制文件、仅元数据变化和
没有改动的文件分别显示对应状态；非 Git Workspace 保留普通代码预览。读取沿用了已有
Workspace 权限检查，按字面匹配路径，并将源码和补丁限制在 2 MB 内。预览禁用了外部 diff
驱动和 clean/process 过滤器，没有改变 Git 索引。

## 预览操作

独立的代码标签页已隐藏，聊天中的文件引用仍然可以打开预览。查看完整文件和复制 diff
收进了更多菜单，底栏去掉了重复的源码版本文字。单个改动显示定位改动，多个改动显示
上一个和下一个改动；关闭改动显示后，跳转按钮也随之隐藏。没有改动的文件不显示改动控件。

## 刷新和浮窗行为

加载期间调整的显示设置会应用到加载后的编辑器。代码和 diff 操作只使用当前请求的快照，
源码与补丁不一致时，需要刷新后再提问。鼠标选区变化时复用已有高亮。问答浮窗和更多
菜单遵循统一的 Esc 关闭顺序，停止回复后仍可以再次提问。不存在的文件返回错误，
已删除的文件可以通过聊天中的完整路径重新打开。Git 二进制改动与文件元数据变化
分别显示对应提示。
