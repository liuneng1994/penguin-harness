# Shortcuts without a count limit

- **Date:** 2026-11-15
- **Type:** feature
- **Scope:** `web`, `server`

[中文版](2026-11-15-unlimited-shortcuts.zh.md)

Removed the three-shortcut limit. The shortcut editor and account preferences accepted additional shortcuts, and reopening the page kept every saved entry.

## Details

- Long shortcut lists scrolled inside their panel. The New shortcut button stayed visible below the list, and the folder showed the number saved.
- Existing shortcuts kept their storage format and order. Name and prompt length validation continued to apply.
