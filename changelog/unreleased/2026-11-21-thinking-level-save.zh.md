# 聊天输入框等待思考级别保存完成

- **Date:** 2026-11-21
- **Type:** fix
- **Scope:** `web`

[English](2026-11-21-thinking-level-save.md)

聊天输入框等待思考级别保存完成后，才允许再次选择或发送消息。保存失败时保留原级别，直接切换的确认框保持打开，方便重试。先压缩再切换的流程在级别保存成功后才提示完成。

保存后的 Session 级别也同步更新到直接查询的会话副本，避免会话不在分页列表中时显示旧值。新建对话的选择器复用了 Agent 配置读取逻辑，采用保存返回的配置，并忽略旧读取结果和上一个 Agent 视图的保存结果。
